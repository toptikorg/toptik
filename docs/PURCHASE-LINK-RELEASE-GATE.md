# Purchase path release gate

Tal's permanent instruction, 2026-11-25: a missing or unusable purchase link is a critical sales-path defect. Within existing authorization, preserve evidence, reproduce, repair and verify rather than stopping at an alert. Safety and publishing holds remain binding.

Before accepting new product content, check each promised surface, including the public gallery payload, rendered card, reviewed product photos, and ordinary product link. A working dedicated landing page is not proof of gallery inclusion. Verify exact SKU, product handle and variant, click through on desktop and mobile width, and confirm the destination. Do not create orders or guess mappings.

The Knirps regression in tests/knirps-gallery-purchase-links.test.mjs uses the production monitor's coverage comparator, exercises public-payload composition and protects manual hides and existing editor rows. It runs in the existing npm test CI job. The reviewed supplement only uses the existing public catalog read and approved photos; it does not resume synchronization or media approval.

The general production monitor remains an additional coverage check when an authorized coordinated run is allowed. Do not weaken its missing-link assertion, revive intentionally hidden products, or describe technical build success as live acceptance. Future product types need their own source and coverage checks; the Knirps test is not universal automatic repair.
