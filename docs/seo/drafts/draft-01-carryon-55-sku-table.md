# טרולי 55 ס״מ בגלריית TopTik: מידות היצרן לפי מק״ט (טיוטה)

> טבלת נתונים מגלריית TopTik. תפקידה להשלים את מדריכי הבלוג ("טרולי לעלייה למטוס", "טרולי למטוס: איך מודדים מידות") ולא להחליף אותם: המדריכים מסבירים כללים ושיטת מדידה; הטבלה מרכזת את מידות היצרן של הדגמים שבגלריה. כל הנתונים ממפרט היצרן הרשמי כפי שהוא שמור בגלריה. מידות מותרות בקבינה משתנות בין חברות תעופה — בדקו מול חברת התעופה לפני הטיסה; מידה כאן אינה התחייבות לקבלה בטיסה כלשהי.
